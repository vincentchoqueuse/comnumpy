Fiber Links#

class FiberLink(N_spans: int = 1, *, L_span: float = 80, StPS: int = 1, fs: float = 1, fiber: ~comnumpy.optical.fiber.FiberSpec = <factory>, NF_dB: float = 4, noise_scaling: float = 1, step_type: ~typing.Literal['linear', 'logarithmic'] = 'linear', step_method: ~typing.Literal['symmetric', 'asymetric'] = 'symmetric', use_only_linear: bool = False, step_log_factor: float = 0.4, name: str = 'fiber link', callbacks: ~typing.Dict[str, ~typing.Callable[[...], None]] = <factory>, raman: ~comnumpy.optical.raman.RamanSolution | None = None, seed: int | None = None)[source]#

Multi-span fiber link simulated with the split-step Fourier method (SSFM).

Signal Model#

Each span integrates the nonlinear Schroedinger equation (NLSE) for the complex field envelope \(A(z, t)\):

\[\frac{\partial A(z, t)}{\partial z} = -\frac{\alpha}{2} A(z, t) - j \frac{\beta_2}{2} \frac{\partial^2 A(z, t)}{\partial t^2} + j \gamma |A(z, t)|^2 A(z, t)\]

where \(\alpha = \frac{\ln 10}{10} \alpha_{dB}\) is the attenuation (Np/km), \(\beta_2 = -10^3 D \lambda^2 / (2 \pi c)\) the group velocity dispersion (ps^2/km) and \(\gamma\) the Kerr coefficient (rad/W/km). The NLSE is integrated numerically with StPS split steps per span (symmetric scheme: \(D(\delta z/2)\,N(\delta z)\,D(\delta z/2)\); asymmetric scheme: \(N(\delta z)\,D(\delta z)\)). After each span, an EDFA compensates the loss with power gain \(G\) and adds circular ASE noise of variance \(\sigma^2_{\mathrm{ase}}\):

\[G = 10^{\alpha_{dB} L_{\mathrm{span}} / 10}, \qquad \sigma^2_{\mathrm{ase}} = \kappa \, f_s \, (G - 1) \, h \nu \, n_{sp}, \qquad n_{sp} = \frac{\mathrm{NF} / 2}{1 - 1/G}\]

with \(\mathrm{NF} = 10^{\mathrm{NF_{dB}} / 10}\) the amplifier noise figure and \(\kappa\) a noise scaling factor.

Two polarizations (Manakov). A field shaped (..., 2, N) – the antenna/channel axis of D2 – is propagated with the Manakov equation instead:

\[\frac{\partial E_{x,y}}{\partial z} = -\frac{\alpha}{2} E_{x,y} - j \frac{\beta_2}{2} \frac{\partial^2 E_{x,y}}{\partial t^2} + j \frac{8\gamma}{9} \left(|E_x|^2 + |E_y|^2\right) E_{x,y}\]

The two polarizations share the total intensity, and the \(8/9\) comes from averaging the nonlinearity over the fast random birefringence of a real fibre. It belongs to the model, not to the fibre: fiber.gamma stays the fibre’s Kerr coefficient in both modes, and which equation is integrated is read off the shape of the field, exactly as which pumps are on is read off their powers (D41). A (..., 1, N) field is a single polarization and keeps the scalar NLSE with \(\gamma\).

Axes: declared axis – a full-field signal (N,) or (..., P, N) with P in {1, 2} polarizations.

param raman:

Distributed Raman gain profile, from solve_raman() over this span length (decision D45). Its on-off gain \(G_\mathrm{on\text{-}off}(z)\) is applied step by step inside the split-step loop, so the Kerr term sees the power the fibre actually carries – which is the whole reason a profile is used rather than a lumped gain. The EDFA is reduced by the same amount, so a span stays transparent whether or not it is pumped, and the ASE the solver integrated is added once per span, scaled from its reference bandwidth to fs.

type raman:

RamanSolution, optional, keyword-only

param seed:

Seed of the local generator, which feeds both the Raman ASE and the per-span EDFA seed. Overridden by chain seeding (Sequential.seed, D6).

type seed:

int, optional, keyword-only

raman_step_gain_#

Amplitude gain applied at each split-step, read off the Raman profile at the step boundaries. Derived from the inputs, hence the trailing underscore (D23).

Type:

np.ndarray

raman_sigma2_#

Variance of the Raman ASE added at the end of each span, in the simulated bandwidth \(f_s\).

Type:

float

raises ShapeError:

If the input is neither a full-field 1D signal (N,) nor a polarization pair (..., P, N) with P in {1, 2} (validated in prepare()): a pointwise Kerr step on a multi-channel array would silently produce SPM only (no XPM, no FWM).

Examples

>>> rng = np.random.default_rng(0)
>>> x = 1e-3 * (rng.normal(size=128) + 1j * rng.normal(size=128))
>>> link = FiberLink(2, L_span=80.0, StPS=4, fs=10e9, noise_scaling=0)
>>> y = link(x)
>>> print(y.shape, y.dtype)
(128,) complex128
